PRIVACY POLICY

Last updated: October 2026

This Privacy Policy explains how GameManor Launcher and its official website (gamemanor.app) handle your information. We believe software should respect user privacy by default.

1. Zero Telemetry & No Tracking on Website

This website is a static site. We do not use tracking cookies, advertising pixels, marketing beacons, or third-party behavioral analytics services.

The only browser storage used is your browser's local storage (localStorage), which strictly stores your chosen visual appearance preference (gamemanor_theme: 'dark' | 'light').

2. Public GitHub API Requests

When visiting the Download and Changelog pages, this website may make client-side HTTP requests directly to the public GitHub API (api.github.com) to display the latest release notes and official Windows installer link.

These requests are unauthenticated public reads. No personal information, user identifiers, or authentication tokens are transmitted. Interactions with GitHub are governed by GitHub's Privacy Statement.

3. The GameManor Desktop Application

The GameManor Launcher Windows application operates on an offline-first, local-storage architecture:

  • Local SQLite Storage: All your game records, titles, executable locations, play sessions, and settings reside locally in a SQLite database located at %APPDATA%\Elemental Games Vault\elemental_vault.sqlite.
  • No Cloud Accounts: You do not need to create an account, log in, or link digital store credentials to use the application.
  • No Automatic Telemetry: GameManor does not send background usage statistics, game launch telemetry, hardware telemetry, or session logs to any remote server.
  • Drive & Folder Scanning: Smart Game Import only scans folders explicitly selected by you. It never scans your entire hard drive automatically or transmits directory contents externally.

4. Correspondence & Contact Inquiries

If you contact us via email or open an issue on GitHub:

  • Your email address and message contents are used solely to review and respond to your inquiry.
  • We do not sell, rent, or share your contact information with marketing third parties.
  • Public GitHub issues and discussions are publicly visible by their nature as part of the open-source project.

5. Hosting Infrastructure

This website is hosted statically via Netlify. Like standard web servers, hosting providers may temporarily log technical connection details (such as your IP address and user-agent string) for security, DDoS mitigation, and server diagnostics. See Netlify's Privacy Policy for infrastructure details.

6. Policy Updates

If our data practices change, this policy will be updated with an updated revision date. Substantial updates will be noted in the project changelog.

7. Contact

For privacy-related questions or security inquiries, reach out through our Contact page or email support@gamemanor.app.
