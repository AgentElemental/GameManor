Quick Start

INSTALLATION INSTRUCTIONS

Four quick steps to install GameManor Launcher on your Windows PC.

01

Download Installer

Click the primary download button above to get the latest verified Windows setup executable.

02

Run the Setup

Open the downloaded installer file. If prompted by Windows SmartScreen, click "More info" then "Run anyway".

03

Complete Installation

Follow the standard setup dialog to install GameManor Launcher to your preferred destination directory.

04

Launch & Import

Launch GameManor Launcher. Use Smart Game Import to scan your game folders and start gaming.

Compatibility

SYSTEM REQUIREMENTS

Component Requirement
Operating System Windows 10 (Build 19041 or higher) or Windows 11 (64-bit)
Processor Intel Core i3 / AMD Ryzen equivalent or higher (64-bit CPU)
Memory (RAM) 4 GB RAM minimum (8 GB recommended for multitasking)
Disk Storage Approx. 150 MB for launcher installation + space for local SQLite database
Display Resolution 1280 × 720 minimum (1920 × 1080 or higher recommended)
Security & Privacy No Microsoft Account or cloud registration required. 100% offline-first.

Important Note on Windows SmartScreen

Because GameManor Launcher is a community open-source desktop application that does not use an expensive commercial code-signing certificate, Windows SmartScreen may display an informational notice ("Windows protected your PC") on first launch.

To proceed, simply click "More info" and then click "Run anyway". The application source code is completely public and auditable on GitHub.
