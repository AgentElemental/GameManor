Knowledge Base

FREQUENTLY ASKED QUESTIONS

Quick answers about library organization, playtime tracking, game importing, and system settings.

GameManor Launcher is a standalone Windows desktop game library and location monitor. It acts as a clean, unified dashboard where you can catalog, organize, launch, and monitor your PC games regardless of where they were purchased or installed.
Yes. GameManor Launcher is 100% free and open-source software licensed under the MIT License. There are no subscriptions, paywalls, premium tiers, or in-app advertisements.
GameManor Launcher is built for 64-bit Windows operating systems, specifically Windows 10 (Build 19041 and higher) and Windows 11.
You can add games in two ways:
  • Smart Game Import: Click "Scan for Games" in My Library to scan selected game folders automatically. Review discovered candidates and import them with one click.
  • Manual Addition: Click "Add Game" (or press Ctrl+N) to manually enter the title, executable path, folder location, artwork, and category.
Yes. You can organize games regardless of whether they originate from Steam, GOG, Epic Games Store, itch.io, emulators, or DRM-free standalone installers. Games can be categorized under PC Games, Emulators, VR, or custom collections.
No. GameManor Launcher is a game manager, launcher, and playtime monitor, not a digital storefront or downloader. It points to existing game installations on your local or external drives.
When you launch a game through GameManor Launcher, its background process manager captures the operating system process ID (PID). It monitors the process until exit, calculating playtime down to the second and recording a detailed session log in your local SQLite database.
GameManor Launcher includes an automatic location monitor. If an external drive is detached or a directory is moved, the game card displays an informational badge ("Drive Not Connected" or "File Missing") and safely prevents launch attempts rather than crashing.
Download the latest installer from the official Download page or GitHub Releases. Running the new installer upgrades your installation in place. Your library records, settings, and playtime history in %APPDATA%\Elemental Games Vault are completely preserved.
All application data is stored locally on your PC in a SQLite database at:
%APPDATA%\Elemental Games Vault\elemental_vault.sqlite
No account registration or cloud server connection is required.
Open Settings in GameManor Launcher and scroll to the Data & Backup card. Click "Create Backup Now" to generate a timestamped SQLite safety copy. You can restore from a previous backup file at any time with automatic SQLite integrity validation.
