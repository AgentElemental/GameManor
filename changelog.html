v1.0.0 Stable Latest Release

October 2026

The initial stable release of GameManor Launcher, providing a modern, private desktop vault for organizing PC game libraries, tracking gameplay sessions, and launching executables with zero third-party telemetry.

New Features

  • Smart Game Import: Added a cautious directory scanner that identifies game installations with Unity, Unreal, GOG, and Steam heuristics, filters out noise executables, and handles path normalization to prevent duplicate imports.
  • Help Center: Created a dedicated in-app Help Center with interactive cards for Keyboard Shortcuts, FAQs, and Contact support.
  • Centralized Shortcut Registry: Added Ctrl+K search focus, numbered navigation Ctrl+1..5, Ctrl+N add game, and input isolation.
  • Dual Theme System: Fully audited high-contrast Light mode alongside the signature dark red-and-black gaming aesthetic.
  • Maintenance Tools: Safe cache clearing, playtime statistic resets, and pre-reset SQLite database backup creation.

Architecture & Reliability

  • SQLite Database Migration Engine: Versioned, transactional migrations preserving existing game records, playtime sessions, and settings.
  • Real-Time Process Monitoring: Live detection of running executables using OS process IDs with instant top-bar status indicators.
  • Location & Drive Availability Monitor: Background checker detecting missing files and unplugged external drives.
  • Custom Frameless Title Bar: Integrated custom title bar with minimize, maximize, restore, and close controls.
