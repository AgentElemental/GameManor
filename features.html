Architecture & Capabilities

BUILT FOR SPEED. ENGINEERED FOR CONTROL.

Every feature in GameManor Launcher is designed around a single principle: giving PC gamers clean, distraction-free ownership of their game library without unnecessary overhead.

Core Engine

DYNAMIC LIBRARY MANAGEMENT

Browse your entire game collection seamlessly. Switch between high-density cover card grids and detailed data lists with persistent display preferences.

Multi-category grouping: Filter by PC Games, Emulators, VR, and custom platform tags.
Instant filtering & search: Real-time filtering by status (Owned, Wishlist, Installed) or title search.
Independent view persistence: Remembers your view preferences across application sessions.
New in v1.0

SMART GAME IMPORT ENGINE

Import games from anywhere on your PC without giving up control. Select specific game directories and let the cautious discovery engine identify playable installations.

Engine & layout heuristics: Detects Unity, Unreal Engine, GOG, Steam, and Godot directory structures.
Noise exclusion filters: Automatically skips uninstallers, crash handlers, updaters, and anti-cheat binaries.
Normalized duplicate detection: Protects against duplicate entries using case-insensitive path comparisons.
Pre-import editing: Clean up titles, adjust paths, and pick which candidates to import into your vault.
Execution

DIRECT EXECUTABLE LAUNCHING

Launch PC games directly with custom working directories and command-line arguments. The launcher continuously monitors the active process PID to keep your vault updated in real time.

Process isolation: Launches the game as an independent OS process without wrapper overhead.
Live active indicators: Dynamic top-bar pill and sidebar counters show currently running games.
Conflict prevention: Prevents duplicate launch attempts while an instance is already active.
Analytics

PRECISE PLAYTIME ANALYTICS

Know exactly how much time you have invested into every game. GameManor tracks timestamps for every gaming session and computes aggregate statistics automatically.

Per-session logs: Individual records detailing session start time, duration, and completion status.
Most-played rankings: Real-time leaderboard highlighting your top games by accumulated hours.
Crash recovery: Recovers stale or interrupted sessions automatically if your computer restarts unexpectedly.
Reliability

INSTALLATION & DRIVE MONITORING

Keep external drives and secondary storage organized. GameManor's background monitor checks file and drive availability automatically.

External drive awareness: Clear badges show whether a game's drive is connected or unmounted.
Status badges: Instant visual indicators for Available, Drive Not Connected, and File Missing.
Safe failure handling: Descriptive error warnings prevent crashes if an executable cannot be found.
Productivity

CENTRALIZED SHORTCUT REGISTRY

Navigate your gaming collection without lifting your hands from the keyboard. A unified shortcut registry powers both in-app hotkeys and the Help Center view.

Global search: Press Ctrl + K to instantly focus search.
Numbered navigation: Jump between Home, Library, Stats, and Settings via Ctrl + 1..5.
Input isolation: Hotkeys are suppressed when typing in text fields to prevent accidental navigation.
Customization

SETTINGS, BACKUPS & DATA PRIVACY

You own your data. GameManor includes built-in database backup tools, SQLite integrity checks, theme switching, and safe cache management.

Theme system: Sleek crimson-and-black Dark mode and clean high-contrast Light mode.
Live database backups: Export safety copies of your SQLite database at any time with integrity verification.
Windows startup & tray: Optional auto-start with Windows and seamless minimization to system tray.
